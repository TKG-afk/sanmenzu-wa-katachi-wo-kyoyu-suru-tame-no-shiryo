# 三面図は、形を共有するための資料

AIによる三面図作成と3DCG作品改善を学ぶ13枚の日本語WEBスライド。

index.htmlで起動。左右キー・Spaceで移動、Tで目次、Nで講師ノート、Fで全画面。画像はクリックで拡大、プロンプトはコピーボタンで取得できます。

画像の限定引用は工程比較・批評の本文と不可分です。包括的な転載許諾や素材ライセンスではありません。出典・利用条件はsources.mdと各画像近傍を参照してください。公開版でも引用箇所を明確に区別し、目的・比較・観察課題を維持しています。

元の24枚版の11〜23ページを切り出した教材です。実際のMuse出力や学生作品の改善実績と教材例を区別しています。
